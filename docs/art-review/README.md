## 엘프 전용 재단

`fit-0.png`, `fit-10.png`는 각 투구의 인간/엘프 착용 비교다. 옆면 귀 자리 절개가 있는 `Elf_Helmet_03, 05, 07, 09, 11, 16, 17, 18, 19, 20`을 엘프 전용으로 판정했다. 열린 왕관·머리핀·머리띠와 엘프풍 무기·의복에는 종족 제한을 붙이지 않았다.

판정 원본은 `src/shared/lib/character/equipment-fit.json`. 스프라이트 파일명이 아니라 명시적인 검수 목록으로 판단하며, 같은 그림을 사용하는 모든 게임 아이템 ID에 적용한다. 하이엘프·우드엘프·다크엘프·문엘프와 기존 elf/darkelf ID를 허용한다.

- 미리보기: 한글 이름 직접 선택·검색, 비엘프에서 전용 항목 비활성화, 다음/이전에서 건너뛰기, 종족 변경/랜덤 외형 시 자동 해제.
- 실제 장착: 아이템 ID 기반 검증, 저장 장비 복원 시 부적합 항목 제거, 부적합 아이템 능력치 제외.
- 백엔드 동반 변경: `PATCH /api/profile`에서 장비/종족의 최종 조합을 행 잠금 트랜잭션 안에서 검증. 프론트에서 전달하는 제한 메타데이터를 신뢰하지 않는다.
- 종족: 데이터에 playable로 표시된 14종을 생성 화면에 연결. 전체 17종의 신체 매핑을 지원하며 상태창과 전투 미리보기에서 인간으로 강제 표시하던 오류를 수정했다.

## 운영 상태 확인

2026-09-27 확인 시 Vercel 웹은 응답했고, 배포된 JS의 API 주소는 `https://kr-icn-db6aac61.colyseus.cloud`였다. 이 주소의 `/health`는 브라우저에서 `ERR_NAME_NOT_RESOLVED`였다. 저장소는 NestJS + Colyseus 서버와 자체 JWT를 구현했지만 DB는 여전히 Supabase Postgres를 사용한다. 이번 변경의 운영 배포는 수행하지 않았다.

추가 브라우저 회귀: 프로덕션 빌드에서 첫 종족 선택부터 Unity의 실제 `bodyIndex=9`를 확인하고, 투구 `helmetIndex=4` 착용 → 동부인 변경 시 `bodyIndex=11, helmetIndex=-1`을 확인했다. Unity의 로딩 플래그뿐 아니라 인스턴스와 스프라이트 준비 이벤트까지 기다린 뒤 조작을 허용한다. 기본값은 첫 사용자 이벤트에서 덮어쓰지 않고 준비 완료 시 한 번 적용한다.

최종 `/test/unity`에서도 한글 이름 검색/직접 선택, 오른손 검→지팡이→해제, 양손 장비와 부위별 착용을 실제 Unity 이벤트 및 `character-panel-final.png`로 확인했다.
